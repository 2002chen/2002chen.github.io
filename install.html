小菜鸟带你飞

不用下载安装包。按你的手机系统操作，桌面会出现网站图标。

iPhone / iPad

  1. 必须用 Safari 打开 2002chen.github.io。
  2. 点底部中间的“分享”按钮（方框加向上箭头）。
  3. 向下滑，选择“添加到主屏幕”。
  4. 确认名称，点右上角“添加”。

如果看不到底部工具栏，先向上滑一下页面。

安卓

  1. 用 Chrome 或手机自带浏览器打开网站。
  2. 点右上角三个竖点菜单。
  3. 选择“添加到主屏幕”“安装应用”或“添加到桌面”。
  4. 点“添加”确认，回到桌面查看图标。

鸿蒙 HarmonyOS

  1. 用华为或荣耀自带的“浏览器”打开网站。
  2. 点底部四个点的“更多”按钮。
  3. 选择“添加到桌面”。
  4. 确认名称，再点“添加到桌面”。

找不到入口？

先退出微信内置浏览器

如果你是在微信中打开，点右上角三个点，选择“用浏览器打开”，再按对应系统的步骤操作。添加后几乎不占存储空间；网站支持 PWA 时会以独立窗口打开。
