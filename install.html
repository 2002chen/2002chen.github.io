iPhone安卓鸿蒙
安装后桌面显示这个图标

系统版本不同，菜单名称可能是“添加到主屏幕”“添加到桌面”或“安装应用”。

01

iPhone / iPad

使用 Safari

Chrome 的菜单不同，iPhone 建议直接使用苹果自带 Safari。

  1. 1
    用 Safari 打开网站

    访问 2002chen.github.io。

  2. 2
    点底部“分享”

    图标通常是一个向上的箭头。

  3. 3
    选择“添加到主屏幕”

    如果没看到，向下滑动分享菜单。

  4. 4
    点右上角“添加”

    回到桌面，找到“小菜鸟”图标。

02

Android

使用 Chrome

三星、小米、OPPO、vivo 等手机显示文字可能稍有不同。

  1. 1
    用 Chrome 打开网站

    确认地址是 2002chen.github.io。

  2. 2
    点右上角“三个点”

    打开浏览器菜单。

  3. 3
    选择安装入口

    点击“安装应用”或“添加到主屏幕”。

  4. 4
    确认安装

    桌面出现图标后即可直接打开。

03

HarmonyOS

使用华为浏览器

部分机型需要先允许浏览器创建桌面快捷方式。

  1. 1
    用华为浏览器打开网站

    不要停留在微信内置页面。

  2. 2
    点“更多”

    入口通常在底部四点菜单中。

  3. 3
    选择“添加到桌面”

    按系统提示确认创建快捷方式。

  4. 4
    检查桌面图标

    若没有出现，请在系统设置中允许浏览器创建快捷方式。

找不到入口？

先退出微信内置浏览器

点微信右上角三个点，选择“在浏览器打开”，再按照对应系统操作。
